# Простой калькулятор

Консольная программа на Python для базовых арифметических операций: сложение, вычитание, умножение и деление.

## Возможности

- Ввод двух чисел (поддерживаются дробные значения)
- Выбор операции: `+`, `-`, `*`, `/`
- Защита от деления на ноль
- Понятный вывод результата

## Требования

- Python 3.x

## Запуск

```bash
python main.py
```

## Пример использования

```
Enter your first number: 10
Enter your second number: 4
Enter operation (+,-,*,/): /
2.5
```

## Структура проекта

```
.
```

## Возможные улучшения

- Обработка некорректного ввода (например, буквы вместо чисел)
- Поддержка дополнительных операций (возведение в степень, остаток от деления)
- Вынесение логики в функции для удобства тестирования
- Локализация сообщений (например, на русский язык)
