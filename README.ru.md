Рандомайзер чисел:

Консольная програма написаная на языке пайтон с помощью которой вы можете генерировать рандомные числа

Возможности:
- Вывод рандомного числа в консоли
- Выбор диапазона чисел для генерации
- Программа сама проверяет чтобы первое число не было больше второго

Требования:
Python 3.X
500B свободного места на диске

Запуск: 
python Randomizer.py

Пример использования:
Enter first number 12
Enter second number 46
37

Лицензия:
Свободное использование
